# Adminer Helm Chart

![version](https://img.shields.io/badge/version-0.1.0-blue)
![version](https://img.shields.io/badge/appVersion-5.42.0-green)

Unofficial Helm Chart for deploying Adminer on Kubernetes.

Adminer is a full-featured database management tool written in PHP. It consists of a single file ready to deploy to the target server. Adminer Editor offers data manipulation for end-users.

Official project repository:  
<https://github.com/vrana/adminer>

## Basic Installation

```bash
helm install adminer oci://ghcr.io/dofevine/charts/adminer
```
